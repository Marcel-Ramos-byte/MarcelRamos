Case Study

Integração de Rede Corporativa e Academica

Implementação completa no Cisco Packet Tracer com VLANs, roteamento, VPN, Wi-Fi, DHCP e validação de conectividade.

Voltar para a pagina principal

Contexto do Projeto

Durante minha trajetoria de estudos no grupo de ciberseguranca da faculdade, um colega propos um desafio interessante: aplicar nossos conhecimentos teoricos em redes de computadores atraves de um projeto pratico completo. A ideia era simular um cenario real de integração entre um ambiente universitario e corporativo, utilizando o Cisco Packet Tracer.

Aceitei o desafio com entusiasmo, pois seria uma excelente oportunidade para consolidar conceitos de VLANs, roteamento, VPN, seguranca de rede e servicos essenciais. Este case study documenta todo o processo de implementação, desde o planejamento ate os testes finais de validação.

Enunciado do Desafio

Objetivo Geral: Desenvolver, no Cisco Packet Tracer, uma infraestrutura de rede hibrida que represente a integração entre um ambiente universitario e corporativo, utilizando conceitos avancados de VLANs, roteamento, VPN, conectividade sem fio, DHCP, enderecamento estatico e servicos de rede.

Requisitos Principais

  • Rede do Campus: 4 VLANs (1 administrativa + 3 academicas)
  • Rede do Escritorio: 3 VLANs (servidores admin, servidores academicos, funcionarios)
  • VPN: Conexao segura entre Campus e Escritorio
  • Wi-Fi: Rede sem fio em uma VLAN academica
  • DHCP: Configurado em determinadas VLANs
  • Servicos: HTTP, FTP nos servidores
  • Politicas de Seguranca: Controle de acesso entre VLANs

7. Conclusao e Aprendizados

Requisitos Implementados

  • Topologia hibrida Campus-Escritorio com 7 VLANs funcionais
  • Roteamento inter-VLAN via switches Layer 3
  • Conexao WAN entre sites via roteamento estatico (172.16.0.0/30)
  • Politicas de acesso entre VLANs implementadas
  • DHCP configurado nas VLANs academicas (20, 30, 40)
  • Servicos HTTP e FTP ativos e acessiveis nos servidores
  • Wi-Fi operacional com WPA2-PSK na VLAN 20
  • Comunicação Campus-Escritorio validada via testes

Dificuldades que encontrei e não consegui implementar no Packet Tracer

Observações Tecnicas:

1. ACLs em Switches 3650: Comandos de ACL sao aceitos na configuração, mas nao bloqueiam trafego conforme esperado.

2. Crypto Maps: Politicas IPSec podem ser configuradas, mas nao podem ser aplicadas em interfaces de switches no Packet Tracer. Solução: roteamento estatico via WAN.

3. DHCP Gateway: Em alguns casos, o DHCP entrega gateway incorreto. Solução: configuração de IP estatico quando necessario.

Importante: Estas limitações sao exclusivas da minha tentativa em seguir o escopo do desafio no simulador e nao refletem o comportamento de equipamentos Cisco reais.

Principais Aprendizados

Este projeto consolidou conhecimentos em:

  • Segmentação de rede: Uso de VLANs para isolar trafego e criar politicas de segurança
  • Roteamento: Implementaçao de roteamento inter-VLAN em switches L3 e roteamento estatico entre sites
  • Servicos essenciais: Configuração de DHCP, HTTP, FTP em ambiente corporativo
  • Conectividade sem fio: Implementaçao de Wi-Fi com autenticaçao WPA2
  • Troubleshooting: Diagnostico e resoluçao de problemas de conectividade
  • Documentação tecnica: Importancia de registrar configuraçoes e testes realizados
Resultado Final: Acredito que todos os requisitos do desafio foram implementados e validados com sucesso. O projeto esta pronto e demonstra competencia em design, implementação e troubleshooting de redes corporativas.

Configurações Basicas

Criar VLAN
configure terminal
vlan 10
name ADMIN
exit
Configurar IP em interface VLAN (SVI)
configure terminal
interface vlan 10
ip address 192.168.10.1 255.255.255.0
no shutdown
exit
Configurar DHCP Pool
configure terminal
ip dhcp excluded-address 192.168.20.1 192.168.20.10
ip dhcp pool VLAN20
network 192.168.20.0 255.255.255.0
default-router 192.168.20.1
dns-server 8.8.8.8
exit
Configurar porta em modo Access
configure terminal
interface fastEthernet 0/1
switchport mode access
switchport access vlan 10
exit
Configurar porta em modo Trunk
configure terminal
interface gigabitEthernet 1/0/1
switchport mode trunk
switchport trunk native vlan 999
switchport trunk allowed vlan 10,20,30,40
exit
Configurar rota estatica
configure terminal
ip route 10.20.0.0 255.255.0.0 10.0.0.2
exit
Habilitar roteamento (Switch L3)
configure terminal
ip routing
exit
Salvar configuração
write memory
ou
copy running-config startup-config
